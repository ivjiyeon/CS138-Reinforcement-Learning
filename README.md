# CS 138 Reinforcement Learning Course Work

This repository contains course assignments and experiments completed as part of Tufts University CS 138: Reinforcement Learning.

It is educational course work and is intended for learning, assignment submission, and academic exploration rather than production use.

## Contents

- Multi-armed bandit experiments and analysis
- Monte Carlo methods for grid-world reinforcement learning
- Assignment-specific scripts, notebooks, and generated outputs

## Purpose

The code in this repo is used to explore core reinforcement learning concepts such as:

- multi-armed bandits
- epsilon-greedy and softmax strategies
- Monte Carlo methods
- policy evaluation and control
- grid-world environments and trajectory-based learning

## Notes

These files are part of a university course and may be incomplete, exploratory, or tailored to assignment requirements.
